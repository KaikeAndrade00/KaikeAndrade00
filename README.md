## 🧠 What I do

- 🏛️ **Data Warehousing & Modeling:** Building Bronze/Silver/Gold layers (Medallion Architecture), Star Schema models, and ETL scripts with stored procedures in SQL Server and PostgreSQL.
- 🔍 **Exploratory Data Analysis (EDA):** Transforming raw data into business insights, cohort analysis, customer behavior, and risk identification.
- 📊 **Business Intelligence (BI):** Designing decision-driven dashboards, DAX measures, and executive KPI reports using Power BI.
- 🤖 **Machine Learning & Applied Analytics:** Developing classification and regression pipelines using Python (Scikit-Learn, Pandas) focused on real-world problems.
- ⚙️ **Data Pipelines & Automation:** Writing Python scripts for data ingestion, cleaning, transformation, and API consumption.

🌱 **Currently learning / exploring:** Docker for Data Pipelines & Containerized MLOps.
