## 🧠 What I do

- 🏛️ **Data Warehousing & Data Modeling:** Designing Star/Snowflake schemas, Medallion Architecture (Bronze, Silver, Gold), and ETL/ELT pipelines using SQL Server & PostgreSQL.
- 🔍 **Exploratory Data Analysis (EDA) & Insights:** Uncovering actionable patterns, calculating churn, revenue at risk, and cohort behavior.
- 🤖 **Machine Learning & Predictive Modeling:** Developing classification, regression, and clustering algorithms (Scikit-Learn, Pandas) with explainability (SHAP).
- 📊 **Business Intelligence (BI):** Building decision-driven dashboards and KPI metrics with Power BI.
- ⚙️ **Software & Distributed Systems:** Developing REST APIs, socket/gRPC services, and automation scripts using Python, Java (Spring Boot), and .NET.
- ☁️ **DevOps & Cloud:** Deploying virtual machines, configuring firewall rules, and containerizing workflows with Docker on Google Cloud Platform (GCP).
